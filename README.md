# 📊 Sales Performance & Revenue Analysis Dashboard (Excel)

## 📌 Executive Summary
This project presents an interactive **Sales Performance Dashboard** created using **Microsoft Excel**. The goal is to analyze overall sales performance, track KPI achievements, identify top-performing product categories, and evaluate sales representative performance across different regions.

---

## 🛠️ Key Tools & Features Used
* **Power Query:** Imported and cleaned raw data (handling duplicates, missing values, and data formatting).
* **Data Modeling & Pivot Tables:** Built structured pivot tables and calculated core metrics (`SUMIFS`, `AVERAGEIFS`, `XLOOKUP`).
* **Dynamic Visualization:** Designed a clean, interactive dashboard utilizing **Slicers** for dynamic filtering by Region, Category, and Year.

---

## 🔍 Key Insights & Findings
* **Total Revenue:** Generated **$1.24M** across **8,420 orders** with an average order value of **$147**.
* **Target Achievement:** Achieved **92%** of the overall revenue target.
* **Top Category:** **Electronics** is the leading product category in revenue generation.
* **Regional Performance:** The **South region** accounts for the highest market share at **29%**, followed by the **North region** at **23%**.
